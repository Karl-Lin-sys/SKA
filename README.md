# Sunny Kids Academy「課程計畫引導師」面接戦略 & 学習科学ポートフォリオ

Sunny Kids Academyの「課程計畫引導師」採用面接に向けた、学習科学の知見（心智圖/マインドマップ vs. 能動的想起）およびご自身の強み（NLP/自然言語処理・各種資格修了証）を融合させた、インタラクティブなシングルページWebアプリケーション（ポートフォリオ）です。

## 主な機能と特徴

1. **概要・役割（Overview）**
   - Sunny Kids Academyの教育方針「持ち運べる能力の育成」およびOtto2プログラムの3ステップ（引導想像、創作呈現、親子共享）を整理。
   - 「課程計畫引導師」に求められる職務要件と言語学・NLP的アプローチの適応表。

2. **学習科学の功罪（Learning Science）**
   - マインドマップ（心智圖）が誘発する「能力の錯覚（Illusion of Competence）」の認知バイアスの図解と解説。
   - 近年のメタ分析データによる心智圖の有効性エビデンス。

3. **想起マッピング（Retrieval Mapping）シミュレータ**
   - 能力の錯覚を回避し、脳への「思い出す負荷」を高めて記憶を長期定着させるためのハイブリッド学習ワークフローを擬似体験できるインタラクティブステップ機能。

4. **最先端研究の動向（Karpicke vs. 2023）**
   - 2011年のScience誌に掲載されたKarpicke & Blunt研究（能動的想起の優位性）と、2023年の追試（学習時間の同等制御による優位性の見直し）の論争をインタラクティブなチャートで解説。
   - 教育現場における両手法の相補的活用法。

5. **面接対策シミュレータ（Interview prep）**
   - 面接官の想定質問（NLPと言語教育の親和性、心智圖への批判に対する科学的提案、Barbara Oakley教授のMOOC修了証のアピール）に対する最適な返答モデル表示。
   - キーワードハイライトとテキストタイピングアニメーション、回答の一クリックコピー機能を搭載。

## 起動方法

### ローカルでの直接起動
本プロジェクトは外部ライブラリに依存しない純粋な HTML, CSS, JavaScript（Vanilla）で構築されています。
フォルダ内の `index.html` をお好みのブラウザ（Google Chrome, Edge, Safari等）でダブルクリックして開くだけで即座に動作します。

### 開発用サーバーでの起動 (Node.js)
もしローカルサーバー経由で確認したい場合は、以下のコマンドで起動できます：

```bash
# 簡易サーバーの起動例
npx serve .
```
